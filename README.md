# Naman Gupta | Personal Portfolio

A responsive personal portfolio website made using HTML and CSS.

## Project files
- `index.html` - page content and sections
- `port.css` - page styling, layout and responsive rules

## Run the website
1. Keep `index.html` and `port.css` in the same folder.
2. Open `index.html` in your browser.

## Personalise before submission
- Add your actual college, course, year and school details.
- Replace the email placeholder with your email address.
- Review every project and achievement description before submitting.
- Keep only skills and statements that you can explain.

## Current limitations
This version uses HTML and CSS only. The contact form uses browser built-in
required-field and email checks, but it does not send messages. JavaScript
features such as a theme switcher and custom form validation can be added
after JavaScript has been covered in class.
